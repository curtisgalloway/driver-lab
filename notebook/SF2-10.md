## 2026-10-09 — Mechanical conversion and key matching

Added `migrate.py` and `spec.py migrate`, keeping the format 1 reader unchanged. The command
preserves logical bullet text with internal newlines, derives ids from lead-ins, emits explicit
source/DT anchors, retains original resource metadata and provenance in each report, and marks
pending work with `citation-pass` and `split-mixed`. Inference-nested anchors become report
candidates only: attaching them as read support for an entire conclusion would change its
meaning. Documents receive provisional registry class `doc`, explicitly flagged for the later
citation pass; no document parenthetical or inference is interpreted here. Critical-fact
selection remains for that later reader as well.

Format 1 file lists do not have `license_from`; the CLI requires explicit caller declarations.
The permissive notice supplies `notice`. GPL uses `spdx-line` for the files its resource note
explicitly identifies that way and `license-file` for the remaining tree-license declarations.
In particular the Pi 4B and CM4 files have no individual license mechanism stated in the v1
note: their `license-file` fields are provisional, requiring confirmation during later source
verification. This step opens no sources and does not assert newly verified license evidence.

The first synthetic test run rejected a bracketed tag inside a link destination: the legacy
Markdown profile already refuses that destination. Changed the test to assert rejection.
Comparison against the three records then caught punctuation in the docs Gotchas keys: the
record retains the lead-in's final period. Added exact sibling-record mapping, checking both
position and lead-in, and refusing missing, duplicate or mismatching keys. The reports now
match all 65 keys exactly. None of the verdict judgments is copied.

Draft specs and root markers are under `scratch-sf2-10/<repo>/specs-v2/`, with each report at
`scratch-sf2-10/<repo>/migration-report.md`. These are transfer artifacts for the orchestrator,
not files to commit to driver-lab. Specs retain their source-file SPDX license headers; root
names, layer, license and accepts stay as in the inputs, with `format: 2` added.

The combined `spec.py check --require-license` run found zero errors and 65 warnings, all
unverified facts (docs 34, permissive 13, GPL 18). No records exist at this stage. The later
citation pass, mixed-bullet splits, fidelity check, source resolution and verdict carry remain
outside SF2-10a.
