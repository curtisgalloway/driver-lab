# LS12: consumers updated

**Terms:** a *consumer* is another repository that names these skills by name (`fuchsia-skills`,
`bringup-kit`, `public-skills`); a *handoff by name* is a skill telling the agent to invoke
another skill; a *spec root* is a directory with a `board-specs.yaml` marker stating its license
and accepted source licenses; the *historical records* are files that quote the old names as
they were (all in the [glossary](../GLOSSARY.md)).

[LS12](../docs/LICENSE-SPLIT-PLAN.md#ls12--consumers-updated). Notebook: [LS12](../notebook/LS12.md).

## What `rpi-expert` became

Nothing. The per-board experts were removed from driver-lab (commit `6f69cf5`, "Remove the
published board specs and per-board expert stubs"); `board-expert` reads specs and none ship. The
two handoffs now name skills that exist: `fuchsia-source` points at `cleanroom-investigator`
(clean-room case) or `hardware-investigator` + `board-expert` (citable case);
`fuchsia-driver-bind-debug` points at `board-expert` when the board has a spec, otherwise
`hardware-investigator`. The README and onboarding text say no per-board expert ships today.
