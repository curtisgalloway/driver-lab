# Plan amendment 2026-09-25: review evidence

## Terms

- **Plan** — the [implementation plan](../IMPLEMENTATION-PLAN.md); **deferred plan** — the
  [material moved out of it](../DEFERRED-PLAN.md).
- **Consultation** — a Claude–Codex exchange that reached consensus on the amendment text.
- **Checkpoint** — the local commit preserving the reviewed change.

See the [glossary](../GLOSSARY.md). This is planning evidence, not evidence that any unit ran.

## What changed and why

A Claude–Codex consultation on 2026-09-25 reviewed the weight of the plan and its process and
agreed on five amendments; the user adopted that exact text the same day. The agreed text is
kept in the private run store. The change applies it:

1. L02g folded into L02f3 as its acceptance stage (one final isolated run set, one A1–A7
   table stating how the revised spec meets or falls short of A1's two-reading requirement,
   an independent review; shortfalls Q18 and Q24–Q26 stated rather than the campaign
   extended). L02f2b stays separate.
2. L02f2b's H1 fix replaced: traffic keeps running through shutdown (the harness already
   stops both floods after the interface goes down), plus a bounded settling interval after
   carrier returns, confirmed from traces; no ping retry; requalification criteria listed.
3. Review default: one independent reviewer (diff plus run artifacts) for harness units,
   `spec-verifier` for spec units, `review-swarm` only for shared machinery, access controls
   or several scenarios, or on the reviewer's request. Checks: changed-surface tests and the
   privacy check locally; the full suite in CI and at the final checkpoint.
4. Records, one job each: run ledger, evidence file, notebook, plan and index.
5. Deferred material and the historical L01 conventions and input snapshot moved verbatim to
   `DEFERRED-PLAN.md`; the plan keeps the disposition table, D7/D8 and the active blockers.

Files: the plan (938 → 533 lines), `DEFERRED-PLAN.md` (new, 529 lines: 502 moved lines, a
title, an intro, a Terms block and one heading for the moved checks paragraph), `AGENTS.md`
(checks, review and records rules replaced; orchestrated mode noted), `GLOSSARY.md` (three
terms), `README.md` (link to the deferred plan), `TRANSITION.md` (marked a superseded
snapshot), and one relinked anchor in `evals/enc28j60/reconstruction/M01-PREPARATION-v1.md`.
