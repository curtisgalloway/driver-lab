# CR2: sanitized verification provenance

**Terms:** a basis records the inputs behind a verdict; a section slice preserves
part of a reading's scope; dependencies are other spec sections that the verdict
relies on. See the [glossary](../GLOSSARY.md) and
[index format](../skills/campaign-review/INDEX-FORMAT.md).

This extract resolves the independent review's H (hash), D (dependencies),
M (model), S (section/class mapping) and E (adjudication class) findings for all
43 listed entries. Every affected [index entry](../evals/e1000/status.yaml) cites
this file. Record names below are relative to the named run, not private machine
paths. Only identity and scope metadata are extracted; no spec text is published
and no claim is re-verified. The source frontmatter hash and model were checked
against every affected available record when making this extract.

Hashes identify the text actually read, including drafts. Model spelling is
normalized from the recorded verifier name/tag: Claude Opus 5.5 / claude-opus-5-5,
Claude Fable 5.1 / claude-fable-5-1. Section numbers denote the spec, not the manual.
For section slices, the full reading scope and evidence-class union are repeated
so the row is traceable on its own; those classes need not all support each slice.

The earlier non-null dependency lists were implementer reconstructions from
brief cross-checks, not complete declarations recorded by the reader. They are
withdrawn: every affected basis now has `dependencies: null`, requiring C2's
whole-revision widening. No exact dependency set is asserted in this extract.
Current revision-8 status concerns its own unchanged text; unknown dependencies
still require conservative widening on a later change.

Revision-4 section scopes are mappings of record headings/verdict keys and AF-1's
numbered brief, with enclosing §10 retained where no narrower section is named.
Its class mapping is databook for manual-backed values/citations, kernel for the
DMA/statistics/BAR API citations, inference for reset/order/policy arguments, and
source-observed for checking the PHY-extra ordering caveat (not reading driver
source). The earlier standard class is removed: no separate standard-backed
revision-4 change verdict was established. These are metadata mappings, not
verbatim class declarations or newly verified claims. Their public context is
[L02c](L02c.md#other-revision-4-changes) and
[AF-1](AF-1.md#the-two-readings-compared).
