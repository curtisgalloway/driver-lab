# LS10: `hardware-investigator`

Milestone of the [license-split plan](../docs/LICENSE-SPLIT-PLAN.md#ls10--hardware-investigator).

### 2026-10-07 — opening

Goal: LS-R17. Starting revision `433469f`. Order from the plan: SKILL.md and the worked example
before any script.

### 2026-10-07 — decision: gate before reading, not only before citing

The plan says to check "before citing". A check that waits until citation lets an investigator
read, and absorb, a source the root cannot accept. The skill gates every candidate before it is
read for evidence; only the license lines and `LICENSE`/`COPYING` may be read earlier.

### 2026-10-07 — decision: a helper script after all

The worked example first looked scriptable by hand: read the accepts line, compare. `OR`, `AND`
and `GPL-2.0` against `GPL-2.0-only` are where a hand comparison goes wrong, and `spdx.py`
already does it. `license_gate.py` is a thin wrapper, written after SKILL.md and the example.

### 2026-10-07 — decision: three runs in the example

Accepting, refusing-and-stopping, and refusing one source while another is accepted. The third
shows "stop" means stop when the needed source is refused, not "give up when anything is".

### 2026-10-07 — dead end: a fixture the checker could not read

The source trees have to be git repositories for `anchor_check.py`, and a repository cannot be
committed inside one. The example builds them from plain files with three git commands, and the
test does the same.

### 2026-10-07 — review and checkpoint

One reviewer ran the example from the text: no must-fix, one should-fix (how to read a license
before fetching), five nits; resolved or recorded (evidence). Checkpoint commit follows.
