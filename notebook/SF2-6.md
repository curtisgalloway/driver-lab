## 2026-10-08T19:00:17-07:00 — Implementation and first fixtures

Ported shallow/blob-less HTTPS fetch behavior without changing format 1. Git
object reads use `--` before every revision/object argument. Symbols and DT
nodes are matched in Python; source text is never a shell command. Local
`--repo NAME=CHECKOUT` reads the declared commit, ignoring worktree edits.

Decisions: symbol proximity is the existing 200-line preceding window, but a
miss is an error. SPDX expressions compare normalized structure, including
exceptions; deprecated identifier aliases and AND/OR ordering agree. Search
checks scope existence only. `--docs-dir` uses exact document names; missing
bytes fail. DT nodes locate decompiled/source text; binary DT bytes are refused
with a decompilation diagnostic. Drift takes a full new commit, selects one
cited entry, and never rewrites on fetch limits or changed search scopes
(the schema forbids stale on search). Ambiguous text movement becomes stale.

First fixture run: four assertions failed because of fixture construction
(YAML emitted an alias, rtl lacked its metadata, conflict used claim instead
of reading, and a directory failed before the expected path-kind guard).
Fixed the fixtures and reordered path resolution before SPDX reading. The
first full suite then passed 209 tests with the network self-test skipped.
Added the checker stale guard: the design says stale must fail check as well
as resolve. Review remains pending.
