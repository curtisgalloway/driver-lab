# L02f2 — bounded repair and retest

Unit of the [plan](../IMPLEMENTATION-PLAN.md) (L02f). Terms: the **candidate** is
`e1000_l02`, written from the spec alone (L02e); the **reference** is Linux v6.12's `e1000`; a
**round** is one repair by the implementer followed by an isolated rerun of all ten scenarios.
See the [glossary](../GLOSSARY.md).

## 2026-09-25T16:45-07:00 — opening
Goal: repair the candidate's E1 policy (L02f1's V1) so probe completes, then rerun every
scenario isolated and compare past probe for the first time. Budget three rounds (user):
round 1 is E1 only; rounds 2 and 3 take failures found past probe; stop after a round that
fixes nothing new. Implementer Codex, model `gpt-6-astra`. Start: branch
`driver-porting/l02f2` from `origin/main` at `1584e32`, own worktree, no local changes.
Private run `e1000-l02f2-20260925-01`; its workspace holds only spec revision 4, the manual
text, the candidate and kernel `include/` and `Documentation/`, hashes as pinned.

## 2026-09-25T16:45-07:00 — decision: read isolation by bubblewrap, audit by strace
The test host also holds the reference source and the planted-defect copies, and Codex's own
sandbox limits writes, not reads. The implementer therefore runs under bubblewrap (only the
workspace, a fresh Codex home, and read-only system directories visible), and strace logs
every file, process and network call. The user asked for the pattern to be codified: it is
now `cleanroom_sandbox.sh` and `sandbox_audit.py` in `cleanroom-implementer`. The fresh home
matters as much as the sandbox: the operator's Codex home holds old sessions and memories,
some from Codex reviews that read the harness and QEMU.

## 2026-09-25T16:45-07:00 — surprise: the auto-mode classifier, then an outage
Launching Codex was blocked by the auto-mode classifier (copying the Codex credential and
bypassing Codex's own sandbox); the user approved it. Codex then returned 401 Unauthorized
inside and outside the sandbox, and again after a fresh login: the user reports a Codex
outage. While waiting, the sandbox and its audit were written and tested (a bash-only run
shows the host home invisible and the canary read logged), and the round-1 brief written.
