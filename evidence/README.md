# Evidence

One public evidence file per experiment (a rebuild-and-compare run, a campaign round, a trial): its
conclusions, acceptance table, limitations, and findings with their resolutions. Tooling units
keep none; their pull request holds results, checks, review findings and dead ends (AGENTS.md,
"Records"). Tooling records written before 2026-10-14 (SF2, LS except LS8, issue fixes, plan
records, RG1, LINUX-PRIORITY) were deleted that day; links to them go to each file at its last
commit on GitHub.

> **Frozen archive.** The files for work before driver-lab's license split (2026-10-06) are kept
> as history and are no longer updated: L01, L02 (`L02*`), the follow-ons (`AF-1`, `CF-*`,
> `CS-1`, `FC-1`, `QF-1`, `SF-1`, `SR-*`), continuous review (`CR*`), and the trial and design
> records (`M01`, `M02a*`, `DESIGN-2026-09-26`). The clean-room
> skills they name now live in
> [cleanroom-skills](https://github.com/curtisgalloway/cleanroom-skills), with their
> [design](https://github.com/curtisgalloway/cleanroom-skills/blob/main/DESIGN.md), and new
> evaluation rounds run from there; names and paths in those files are as they were then
> (`os-investigator` is now `cleanroom-investigator`). `LS8` records the license split's documents
> step (`check-open-side.py` cites it) ([plan](../docs/LICENSE-SPLIT-PLAN.md)). See the
> [license-split design](../docs/LICENSE-SPLIT.md), requirement LS-R20.
